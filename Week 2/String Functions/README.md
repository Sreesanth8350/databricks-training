# SQL String Functions Assignment

## 📌 Overview

This project helps in learning **String Functions** in MySQL for text manipulation, formatting, extraction, and NULL handling.

It includes:

* Table creation
* Insert statements
* String manipulation queries
* Text formatting operations
* NULL handling functions
* Employee data analysis

* `CONCAT()

* `SUBSTRING()

* `RIGHT()

* `LOCATE()
