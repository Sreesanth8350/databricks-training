# SQL NULL Functions Assignment

## 📌 Overview

This project helps in learning **NULL handling functions** in MySQL and how to manage missing data in databases.

It includes:

* Table creation
* Insert statements
* NULL handling queries
* Conditional operations
* Real-world business examples

---

## 📚 Topics Covered

### NULL Functions

* `IS NULL`
* `IS NOT NULL`
* `IFNULL()`
* `COALESCE()`
* `NULLIF()`

---

## 🛠️ Concepts Practiced

* Replacing NULL values
* Handling missing data
* Avoiding divide-by-zero errors
* Using default values
* Conditional NULL handling
* Salary and bonus calculations
* Product and order analysis

## 💻 Tools Used

## 🚀 Learning Outcomes

After completing this assignment, you will be able to:

* Understand NULL values in SQL
* Replace NULL values using `IFNULL()`
* Use `COALESCE()` to return the first non-null value
* Apply `NULLIF()` in conditional comparisons
* Filter data using `IS NULL` and `IS NOT NULL`
* Handle real-world missing data scenarios using SQL
