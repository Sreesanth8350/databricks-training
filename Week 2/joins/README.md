# SQL JOINS Assignment

## 📌 Overview

This project helps in learning **SQL JOIN operations** in MySQL for combining and analyzing data from multiple tables.

It includes:

* Table creation
* Insert statements
* Different JOIN queries
* Aggregate functions
* Employee and department analysis

---

## 📚 Topics Covered

### SQL JOINs

* `INNER JOIN`
* `LEFT JOIN`
* `RIGHT JOIN`
* `FULL OUTER JOIN`
* `SELF JOIN`

### Aggregate Functions

* `COUNT()`
* `GROUP BY()`

---

## 🛠️ Concepts Practiced

* Employee and manager relationships
* Employee-department mapping
* Employee-project assignments
* Finding employees without departments
* Finding departments without employees
* Finding employees without projects
* Handling `NULL` values in JOINs

---

## 📂 Tables Used

* `employees
* `departments
* `projects
* `salaries
* `contacts`
