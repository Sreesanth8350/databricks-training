# SQL REGEX Foundation Assignment

## 📌 Overview

This project helps in learning the basics of **REGEX (Regular Expressions)** in MySQL for pattern matching, data extraction, and validation.

It includes:

* REGEX basics
* Pattern matching
* Digit and alphabet extraction
* Email and phone validation
* String manipulation queries

---

## 📚 Topics Covered

### REGEX Concepts

* Character matching
* Digit extraction
* Alphabet extraction
* Start (`^`) and end (`$`) patterns
* Exact matching using `{ }`
* Continuous matching using `+`
* Special character handling

### REGEX Patterns

* `[0-9]
* `[A-Za-z]
* `[0-9]+
* `[A-Za-z]+
* `[0-9]{2}
* `[A-Za-z]{2}
