# DATE & TIMESTAMP Functions in MySQL

## 📌 Overview

This project helps you learn how to use **DATE** and **TIMESTAMP** functions in MySQL using an `orders` table.

You will practice:

* Creating tables
* Inserting data
* Working with dates and time
* Performing date calculations
* Writing business-related SQL queries

---

## 🎯 What You Will Learn

* MySQL date and time functions
* Extracting year, month, and day
* Formatting dates
* Adding and subtracting dates
* Finding date differences
* Identifying weekdays and weekends
* Writing real-world reporting queries

---

## 📚 Topics Covered

### Current Date & Time

* CURDATE()
* CURTIME()
* NOW()
* CURRENT_TIMESTAMP

### Date Functions

* YEAR()
* MONTH()
* DAY()
* EXTRACT()

### Month & Day Functions

* `MONTHNAME()
* `DAYNAME()
* `WEEKDAY()
* `DAYOFWEEK()

### Date Calculations

* `DATE_ADD()
* `DATE_SUB()
* `DATEDIFF()
* `TIMESTAMPDIFF()

### Formatting

* `DATE_FORMAT()
* `STR_TO_DATE()

### Business Queries

* Orders placed today
* Orders in last 7 days
* Weekend orders
* Delivery analysis
* Financial year reports
