# SQL Window Functions Assignment

## 📌 Overview

This project helps in learning **Window Functions** in MySQL for ranking, numbering, partitioning, and data analysis.

It includes:

* Table creation
* Insert statements
* Ranking queries
* Partition-based analysis
* Aggregate window functions
* Employee data analysis

---

## 📚 Topics Covered

### Window Functions

* `ROW_NUMBER()`
* `RANK()`
* `DENSE_RANK()`
* `NTILE()`
* `LAG()`
* `LEAD()`
* `FIRST_VALUE()`
* `LAST_VALUE()`

### Aggregate Window Functions

* `SUM() OVER()`
* `AVG() OVER()`
* `COUNT() OVER()`
* `MAX() OVER()`
* `MIN() OVER()`

---

## 🛠️ Concepts Practiced

* Assigning row numbers
* Ranking employees by salary
* Partitioning data by department
* Comparing current and previous rows
* Finding top-performing employees
* Calculating running totals
* Computing moving averages
